# Currículo — Carlos Miguel Pereira Gonçalves

Página pessoal / currículo interativo, desenvolvida como projeto do Módulo 1 (HTML5 Semântico + CSS Grid/Flexbox, sem JavaScript).

## Ver online

https://carlosgon-dev.github.io/projeto-curriculo-carlos/

## Tecnologias

- HTML5 semântico (`<header>`, `<main>`, `<footer>`, `<details>`/`<summary>`, `<address>`, `<nav>`, `<hgroup>`)
- CSS3 — Flexbox e Grid, sem frameworks
- Sem JavaScript, à exceção de dois pequenos easter eggs de som (`onclick`/`ontoggle` a tocar um áudio) nos botões do LinkedIn/GitHub e na secção "Sobre mim" — o resto da página (acordeões, cartões de competências, responsividade) é 100% HTML/CSS

## Funcionalidades

- Currículo organizado em acordeão, com `<details>`/`<summary>` nativos (Sobre mim, Experiência Profissional, Lado B, Formação Académica, Certificações, Competências)
- Cartões de competências com efeito de "flip": passa o rato (desktop) ou toca (mobile) para ver as ferramentas de cada categoria
- Totalmente responsivo (desktop e mobile)

## Estrutura

```
projeto_curriculo/
├── index.html
├── style.css
├── images/       # fotos e logótipos
├── icons/        # ícones SVG
└── sons/         # easter eggs de áudio
```

## Como ver localmente

Abre o `index.html` diretamente no browser, ou usa a extensão Live Server do VS Code.
